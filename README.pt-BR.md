## Sobre o Projeto

O **REMAR Acolhimento** é uma plataforma de software real, desenvolvida para a Remar Brasil, uma organização brasileira sem fins lucrativos.

A plataforma foi projetada para centralizar e apoiar processos operacionais e de gestão de acolhimento por meio de um sistema moderno, seguro e de fácil manutenção.

Este repositório é um **estudo de caso técnico e projeto de portfólio**, destinado a documentar a engenharia de software envolvida na construção da plataforma.

O código-fonte de produção é proprietário e não está disponível publicamente.

## 🏗️ Arquitetura

O REMAR Acolhimento utiliza uma arquitetura full-stack moderna:

**Web / Android / iOS**  
↓  
**Vue 3 + Quasar**  
↓  
**API REST**  
↓  
**Node.js + Express**  
↓  
**Prisma ORM**  
↓  
**PostgreSQL**

O projeto também contempla autenticação, autorização, validação de regras de negócio, testes automatizados, migrações de banco de dados e práticas de segurança da aplicação.

Diagramas detalhados de arquitetura e documentação técnica serão adicionados a este repositório conforme o estudo de caso evoluir.
